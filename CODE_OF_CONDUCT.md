# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone taking part is expected to follow it in every project space, including issues,
pull requests and discussions.

In short: be respectful and welcoming, give and accept constructive feedback gracefully, and do not harass,
insult or demean anyone.

## Reporting

Report unacceptable behavior to the maintainer at s076923@gmail.com. All reports are reviewed promptly and
handled confidentially. The maintainer may remove, edit or reject contributions, or temporarily or permanently
ban contributors, for behavior that violates this code of conduct, following the
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
of the Contributor Covenant.
